Technology Stack Overview

Object Detection (YOLOv8)

Utilized for detecting mobile phones and multiple persons in the webcam feed. Provides high-speed inference for real-time bounding box rendering.

Gaze Tracking (MediaPipe)

Uses 468 facial landmarks to track eye iris movement and head pose to detect when a student looks away from the screen for extended periods.

Facial Authentication (ViT)

Uses Hugging Face's Vision Transformer (google/vit-base-patch16-224-in21k) to extract 768-dimensional facial embeddings for highly secure cosine similarity matching.

Audio Diarization (Librosa)

Analyzes 10-second chunks of audio via Root Mean Square energy, Pitch variances (F0), and Spectral Bandwidth to differentiate silence, single voices, and multiple distinct speakers.

Analytics (Matplotlib & Pandas)

Dynamically renders Enterprise-grade KPI charts, pie charts, and scatter plots into Base64 images directly inside the Admin portal.

Web Framework & DB (Flask + SQLite)

The entire backend is powered by Flask routing, with SQLite handling complex multi-student schema modeling, relational session mapping, and bcrypt password hashing.
