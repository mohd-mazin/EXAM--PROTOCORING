
# 🎓 AI-Based Smart Exam Proctoring and Malpractice Detection System

## 📌 Overview

An AI-powered online examination proctoring system developed using Artificial Intelligence, Computer Vision, and Machine Learning. The system monitors students in real time during online examinations and automatically detects malpractice activities.

---

## 🚀 Features

- 👤 Face Verification
- 🎥 Real-Time Webcam Monitoring
- 📱 Mobile Phone Detection (YOLOv8)
- 👥 Multiple Person Detection
- 👀 Eye Gaze Tracking
- 🙂 Head Pose Detection
- 🔊 Audio Monitoring
- 🖥️ Fullscreen Monitoring
- 🔄 Tab Switching Detection
- 📸 Automatic Evidence Capture
- 📊 AI Report Generation
- 🛡️ Admin Dashboard
- 👨‍🎓 Student Dashboard
- 🎬 Exam Replay

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sohan42005/smart_exam_proctoring.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```
